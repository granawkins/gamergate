# Migration Versions

This directory contains Alembic migration scripts. These are generated automatically or manually when database schema changes are needed.

Each file represents a single migration step with:
- Upgrade instructions (to apply the change)
- Downgrade instructions (to revert the change)

## Initial Migration

The initial migration (the first file in this directory) creates the base schema for the application with all tables needed to replace the JSON database.

## Naming Convention

Files are named with a format like:
```
{revision_id}_{descriptive_name}.py
```

For example:
```
a1b2c3d4e5f6_initial_schema.py
```

The revision ID is automatically generated by Alembic.

## Adding a New Migration

When creating a new migration, see the instructions in the parent directory's README.md file.
